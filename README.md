# CliCPlot

**CliCPlot**は症例発表などで使う「経過表」を簡単に作成できるツールです。クリック操作だけでスタイリッシュな経過表が出来上がります！

突然症例発表をするよう言われた。せっかくなら目を引く経過表を作りたいけれど、時間もプログラミング技術も無い。
そんな時、CliCPlotならボタンをクリックしてデータをコピペするだけで、カッコいい経過表が出来ます！

## 使い方
### 使うだけ
[ブラウザ版はこちら](https://tbjustice.github.io/clinical-course-editor/)

基本的な機能は全て使えますが、セキュリティの関係で第三者が作った拡張機能は使用できません。
また、拡張機能の開発も行えません。

### 開発したい
自分で拡張機能を開発したり、第三者が作った拡張機能を使いたい場合、コードのインストールが必要です。
詳しくは下記の「開発する」セクションで説明しています。

## 特徴
- **経過表特化** : 経過表を簡単に作る事に特化
- **オープンソース** : プログラム全文を公開。好きにカスタマイズ可能
- **拡張性** : グラフの種類を増やせる拡張性
- **無料** : もちろん無料で使う事が出来ます

## 開発する
### 事前準備
+ 最新版のNode.jsをインストール
+ このレポジトリをクローン(ダウンロード)
+ コマンドから`npm install`で必要なパッケージをインストール

### 起動
1. コマンドから`npm run dev`でアプリを起動
2. 表示されるURL(`http://localhost:XXXX/clinical-course-editor/`)へブラウザからアクセス
